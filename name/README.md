# Briefe Karl Kraus – Digitale Edition (TEI/XML)

This repository contains a project for the course  
**“Aus dem Archiv ins Frontend. Digitale Editionen als statische Webseiten (2026S)”**  
at the University of Vienna.

## Project Description

The aim of this project is the creation of a small digital edition of three letters written by Karl Kraus.  
The letters are transcribed and encoded using the **TEI (Text Encoding Initiative) XML standard** and published as a static website using the **DSE Static Cookiecutter framework**.

## Corpus

The edition currently includes three letters by Karl Kraus, digitised by the Wienbibliothek im Rathaus:

- Letter 1: https://www.digital.wienbibliothek.at/download/webcache/1000/5397126
- Letter 2: https://www.digital.wienbibliothek.at/download/webcache/1000/5397127
- Letter 3: https://www.digital.wienbibliothek.at/download/webcache/1000/5397128

These sources are used for academic, non-commercial teaching purposes.

## Technologies Used

- TEI/XML for text encoding
- XSLT for transformation to HTML
- HTML/CSS/JavaScript for presentation
- DSE Static Cookiecutter for static site generation
- Git & GitHub for version control and deployment

## Technical Foundation

This project is based on the **DSE Static Cookiecutter** template developed by the ACDH-CH (Austrian Centre for Digital Humanities and Cultural Heritage, ÖAW).

Repository: https://github.com/acdh-oeaw/dse-static-cookiecutter
