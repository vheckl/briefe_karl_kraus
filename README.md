# Briefe Karl Kraus – Digitale Edition (TEI/XML)

This repository contains a project for the course
"Aus dem Archiv ins Frontend. Digitale Editionen als
statische Webseiten (2026S)" at the University of Vienna.

## Project Description

The aim of this project is the creation of a small digital
edition of three letters addressed to Karl Kraus. The letters
are transcribed and encoded using the TEI (Text Encoding
Initiative) XML standard and published as a static website
using the DSE Static Cookiecutter framework.

## Corpus

The edition includes three letters addressed to Karl Kraus,
digitised by the Wienbibliothek im Rathaus:

- **Letter 1:** Henriette von Cleve an Karl Kraus,
  Mondsee, 18. Juli 1934 (2 Seiten)  
  https://www.digital.wienbibliothek.at/id/3524824

- **Letter 2:** Vally Springer an Karl Kraus,
  Wien, 1902 (3 Seiten)  
  https://www.digital.wienbibliothek.at/id/5397125

- **Letter 3:** Margarete Steckell an Karl Kraus,
  Berlin, 4. November 1904 (3 Seiten)  
  https://www.digital.wienbibliothek.at/id/5429274

These sources are used for academic, non-commercial
teaching purposes.

## Technologies Used

- TEI/XML for text encoding
- XSLT for transformation to HTML
- HTML/CSS/JavaScript for presentation
- DSE Static Cookiecutter for static site generation
- Git & GitHub for version control and deployment

## Technical Foundation

This project is based on the DSE Static Cookiecutter template
developed by the ACDH-CH (Austrian Centre for Digital Humanities
and Cultural Heritage, ÖAW).  
Repository: https://github.com/acdh-oeaw/dse-static-cookiecutter
